# 产品定义

> Knowledge Owner：product。本文是产品事实的唯一权威来源。
> 新产品从本模版创建后，重写全文。不要在这里保留模版自我描述。

## 定位

可复制的项目操作系统模版。给新项目提供 Agent 入口、工程规则、文档归属、当前状态和可选领域空壳，避免每次让 AI 从零设计文档系统。

用户不要把本仓库根目录当新产品。本地生成的 `template/` 才是可拿走的实例：拷走后填写产品槽位即可开工。

## 非目标

- 不是业务代码脚手架（不带具体前端/后端/数据库选型）。
- 不是 IDE 插件、宿主 hook、daemon、扫描器。
- 不是任务队列或研发管理平台。

## 原则

1. 操作系统与产品实例分离：OS 可复用，产品事实每个项目自己填。
2. 规则工具中立。
3. 机制服务于开发节奏；用户插话优先于流程仪式。
4. 领域文档按需启用，不预铺。
